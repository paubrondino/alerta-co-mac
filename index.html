Sistema de monitoreo de monóxido de carbono

Descripción del producto

Alerta CO es un prototipo de monitoreo de monóxido de carbono. Utiliza un sensor MQ-7 y una placa ESP32 para procesar las lecturas y transmitir información a una plataforma web mediante Wi-Fi.

Componentes principales

Sensor MQ-7

Detecta la presencia de monóxido de carbono mediante lecturas que procesa la placa.

Placa ESP32

Procesa las lecturas del sensor y permite enviar información mediante Wi-Fi.

Pantalla OLED

Muestra mensajes y estados del dispositivo según la programación.

LED indicador

Permite indicar diferentes estados del sistema según la configuración programada.

Buzzer

Emite una señal sonora cuando se cumplen las condiciones establecidas en el programa.

Conectividad

La placa ESP32 se conecta a una red Wi-Fi y envía las lecturas a la plataforma web para su visualización y seguimiento.
